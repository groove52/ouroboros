Linux Setup Guide - Ouroboros

Version: 1.0

Complete guide to installing Ouroboros on Linux systems. This guide covers Ubuntu/Debian-based distributions.

Prerequisites

  • Ubuntu 20.04+ / Debian 11+ or compatible Linux distribution
  • Python 3.9+ (recommended: 3.11+)
  • Git for cloning the repository
  • Telegram Bot Token (from BotFather)
  • OpenRouter API Key (or other LLM provider)

Installation Steps

Step 1: Install Dependencies

# Update package list
sudo apt update

# Install Python 3.11 (if not already installed)
sudo apt install -y python3.11 python3.11-venv python3.11-dev

# Install Git
sudo apt install -y git

# Install build tools (for Python packages)
sudo apt install -y build-essential

# Install Python package manager (uv)
sudo apt install -y curl
curl -LsSf https://astral.sh/uv/install.sh | sh

# Add uv to PATH
echo 'export PATH="$HOME/.cargo/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

Step 2: Create Project Directory

# Create project directory
mkdir -p ~/.ouroboros
cd ~/.ouroboros

Step 3: Clone Repository

# Clone Ouroboros repository
git clone https://github.com/your-username/ouroboros.git .

# Create virtual environment
uv venv

# Activate virtual environment
source .venv/bin/activate

# Install dependencies
uv pip install -e .

Step 4: Configure Environment

# Create environment configuration
cp config_example.env .env

# Edit .env file with your API keys
nano .env

Edit the .env file with your configuration:

# Required
OPENROUTER_API_KEY=your_openrouter_api_key_here
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# Optional
TOTAL_BUDGET=10.0
OUROBOROS_MODEL=anthropic/claude-sonnet-4.6
OUROBOROS_MODEL_CODE=anthropic/claude-3-5-sonnet-20241022
OUROBOROS_MODEL_LIGHT=anthropic/claude-3-haiku-20240307

Step 5: Initialize State

# Initialize Ouroboros state
python -c "from supervisor.state import init_state; init_state()"

Step 6: Test Installation

# Test basic functionality
python -c "from ouroboros.agent import Agent; agent = Agent(); print('Ouroboros agent created successfully')"

# Test memory system
python -c "from ouroboros.memory import Memory; memory = Memory(pathlib.Path('~/.ouroboros')); memory.ensure_files(); print('Memory system initialized')"

Running Ouroboros

Interactive Mode

# Activate virtual environment
source ~/.ouroboros/.venv/bin/activate

# Start Ouroboros in interactive mode
python -m ouroboros.agent

Background Mode

# Start Ouroboros in background mode
nohup python -m ouroboros.agent --background > ouroboros.log 2>&1 &

# Check status
ps aux | grep ouroboros

# View logs
tail -f ouroboros.log

Systemd Service

# Create systemd service file
sudo nano /etc/systemd/system/ouroboros.service

Add the following content:

[Unit]
Description=Ouroboros AI Agent
After=network.target

[Service]
Type=simple
User=your_username
WorkingDirectory=/home/your_username/.ouroboros
Environment=PATH=/home/your_username/.ouroboros/.venv/bin
ExecStart=/home/your_username/.ouroboros/.venv/bin/python -m ouroboros.agent --background
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target

# Enable and start service
sudo systemctl enable ouroboros
sudo systemctl start ouroboros

# Check status
sudo systemctl status ouroboros

Directory Structure

~/.ouroboros/
├── .env                    # Environment configuration
├── .venv/                  # Python virtual environment
├── ouroboros/             # Main source code
├── memory/                # Persistent memory
│   ├── scratchpad.md     # Working memory
│   ├── identity.md       # Manifesto
│   ├── scratchpad_journal.jsonl  # Memory journal
│   └── dialogue_summary.md  # Dialogue summary
├── logs/                  # Log files
│   ├── chat.jsonl        # Chat history
│   ├── progress.jsonl     # Progress messages
│   ├── tools.jsonl        # Tool usage
│   ├── events.jsonl       # System events
│   └── supervisor.jsonl   # Supervisor events
├── state/                 # State management
│   ├── state.json        # Current state
│   ├── state.last_good.json  # Last good state
│   └── queue_snapshot.json  # Task queue snapshot
└── locks/                 # File locks
    └── state.lock        # State lock file

Configuration Options

Environment Variables

  • OPENROUTER_API_KEY: Required - OpenRouter API key
  • TELEGRAM_BOT_TOKEN: Required - Telegram bot token
  • TOTAL_BUDGET: Optional - Total budget in USD (default: 10.0)
  • OUROBOROS_MODEL: Optional - Primary LLM model (default: anthropic/claude-sonnet-4.6)
  • OUROBOROS_MODEL_CODE: Optional - Code-focused model
  • OUROBOROS_MODEL_LIGHT: Optional - Light model for simple tasks

Command Line Options

python -m ouroboros.agent --help

Available options:

  • --background: Run in background consciousness mode
  • --no-background: Run only in interactive mode
  • --debug: Enable debug logging
  • --config: Specify custom config file path

Troubleshooting

Common Issues

Permission Denied

sudo chown -R $USER:$USER ~/.ouroboros

Missing Dependencies

uv pip install -e .

API Key Issues

# Verify API keys are set
echo $OPENROUTER_API_KEY
echo $TELEGRAM_BOT_TOKEN

# Check connectivity
curl -s https://openrouter.ai/api/v1/auth/key | jq

Logs

# Check system logs
tail -f ~/.ouroboros/logs/events.jsonl

# Check supervisor logs
tail -f ~/.ouroboros/logs/supervisor.jsonl

Security Considerations

  • Keep your API keys secure and never commit them to version control
  • Set appropriate file permissions on ~/.ouroboros directory
  • Regularly monitor usage and budget
  • Consider using a dedicated user account for running Ouroboros
