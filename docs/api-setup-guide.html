API Setup Guide - Ouroboros

Версия документа: 1.0

Что нужно настроить

Ouroboros требует два API ключа для работы:

  1. Telegram Bot Token - для общения с пользователем
  2. OpenRouter API Key - для доступа к LLM моделям

Настройка Telegram Bot Token

Шаг 1: Создание бота в Telegram

1. Найдите @BotFather

Откройте Telegram и найдите пользователя @BotFather.

Это официальный бот для создания и управления другими ботами.

2. Создайте нового бота

/start /newbot

BotFather попросит вас:

  • Дать имя боту (например "Ouroboros")
  • Дать юзернейм боту (должен заканчиваться на "bot", например "OuroborosBot")

3. Скопируйте API токен

После создания бота BotFather предоставит вам API токен вида:

123456789:ABCdefGHIjklMNOPQRstUVwxyz_123456

Сохраните этот токен - он понадобится для настройки.

Шаг 2: Настройка бота

1. Добавьте описание и изображение

/setdescription /setuserpic

Это необязательно, но рекомендуется для идентификации бота.

2. Настройте команды

/setcommands

Добавьте стандартные команды:

/start - Запустить бота
/help - Помощь
/status - Статус системы
/bg - Управление фоновым режимом

Настройка OpenRouter API Key

Шаг 1: Регистрация на OpenRouter

Перейдите на OpenRouter и создайте аккаунт.

OpenRouter предоставляет доступ к множеству LLM моделей по конкурентным ценам.

Шаг 2: Получение API ключа

  1. Войдите в свой аккаунт
  2. Перейдите в раздел "API Keys"
  3. Нажмите "Create API Key"
  4. Дайте ключу название (например "Ouroboros")
  5. Скопируйте сгенерированный API ключ

API ключ будет выглядеть примерно так:

sk-1234567890abcdefghijklmnopqrstuv

Шаг 3: Пополнение баланса

Для использования OpenRouter вам нужно пополнить баланс.

Минимальная сумма пополнения обычно составляет $5-10.

Цены на модели:

  • anthropic/claude-sonnet-4.6 - $0.015/1K токенов
  • openai/gpt-4.1 - $0.020/1K токенов
  • google/gemini-2.5-pro-preview - $0.018/1K токенов

Настройка конфигурационного файла

Шаг 1: Откройте конфигурационный файл

sudo nano /etc/ouroboros/config.json

Шаг 2: Вставьте API ключи

Найдите следующие поля и вставьте полученные ключи:

{
    "telegram_bot_token": "123456789:ABCdefGHIjklMNOPQRstUVwxyz_123456",
    "openrouter_api_key": "sk-1234567890abcdefghijklmnopqrstuv",
    "model": "anthropic/claude-sonnet-4.6",
    "budget_usd": 10.0,
    "log_level": "INFO",
    "state_path": "/var/lib/ouroboros/",
    "log_path": "/var/log/ouroboros/"
}

Сохраните файл и закройте редактор.

Шаг 3: Проверьте права доступа

sudo chown ouroboros:ouroboros /etc/ouroboros/config.json sudo chmod 600 /etc/ouroboros/config.json

Тестирование API подключения

Тестирование Telegram

После настройки конфигурации перезапустите сервис:

sudo systemctl restart ouroboros

Отправьте боту сообщение "/start" - он должен ответить.

Тестирование OpenRouter

Проверьте логи сервиса:

sudo journalctl -u ouroboros -f

Ищите сообщения о подключении к LLM моделям.

Безопасность

Важные замечания

Никогда не публикуйте API ключи

  • Не коммитьте их в репозиторий
  • Не отправляйте в сообщения
  • Храните в безопасном месте

Рекомендации по безопасности

  • Используйте разные ключи для разных сервисов
  • Регулярно меняйте ключи
  • Ограничьте доступ к конфигурационному файлу
  • Мониторьте расходы на API

Устранение проблем

Проблема: Telegram не отвечает

  1. Проверьте токен в /etc/ouroboros/config.json
  2. Перезапустите сервис: sudo systemctl restart ouroboros
  3. Проверьте логи: sudo journalctl -u ouroboros -f
  4. Убедитесь, что бот активен в Telegram

Проблема: Ошибка LLM модели

  1. Проверьте API ключ OpenRouter
  2. Убедитесь, что баланс положительный
  3. Проверьте доступность модели
  4. Проверьте логи на ошибки подключения

Следующие шаги

После настройки API:

  1. Перезапустите сервис: sudo systemctl restart ouroboros
  2. Проверьте статус: sudo systemctl status ouroboros
  3. Проверьте логи: sudo journalctl -u ouroboros -f
  4. Отправьте боту сообщение "/status" для проверки

FAQ

Вопрос: Можно ли использовать другие LLM провайдеры?

Да, Ouroboros поддерживает различных провайдеров. Измените конфигурацию:

{
    "model": "openai/gpt-4.1",
    "openai_api_key": "your_openai_key"
}

Вопрос: Как изменить бюджет?

Измените поле "budget_usd" в конфигурации:

{
    "budget_usd": 20.0
}

Вопрос: Как мониторить расходы?

Ouroboros автоматически отслеживает расходы и предупреждает при достижении лимита.
